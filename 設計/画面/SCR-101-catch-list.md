## 2. 画面概要
投稿された釣果をカードで一覧表示します。共有サイドバーを使い、本画面では釣果一覧を選択状態にします。
画面上部に「釣果一覧」の見出しと絞り込みチップを置き、その下に釣果カードを並べます。カードのタイトルは「月日＋（釣り場名）の釣果」とし、サブタイトルには魚種名と匹数を表示します。サイズ（cm）は表示しません。カード押下で釣果詳細に遷移します。

## 3. 画面レイアウト
レイアウトの正典はFigmaです。ワイヤーは画面構成と操作対象を示します。

- **Figma フレーム URL**: https://www.figma.com/design/LX5UAOYXjKxQougVqVzViq?node-id=1159-2799
- 共有サイドバーの右側にメインコンテンツを配置します。
- メインコンテンツは、見出し「釣果一覧」、絞り込みチップ、釣果カードグリッドで構成します。
- Figmaには22件のサンプルカードを配置しています。カードの実データ件数は別途決定します。

簡易ワイヤー（カードはサンプル22件。下方向に続く）:

```text
┌────────┬────────────────────────────────────────────────────────────┐
│共有    │ 釣果一覧                                                   │
│サイド  │ [✓ すべて] [魚種] [釣り場] [期間] [サイズ]                 │
│バー    │                                                            │
│ map    │ [写真] 10月15日（宇野港）の釣果   …（5列）                   │
│一覧    │        アジ 3匹                                           │
│        │ [写真] 10月15日（下津井）の釣果                           │
│        │        チヌ 1匹                                           │
│検索    │                                                            │
│お気に入り│ 22件のカード。さらに下へスクロール                        │
│ ＋     │                                                            │
└────────┴────────────────────────────────────────────────────────────┘
```

## 4. 画面項目

| No | 項目名 | 種別 | 必須 | 説明・制約（桁数 / 形式 / 初期値 など） |
| --- | --- | --- | --- | --- |
| 1 | 共有サイドバー | 共通コンポーネント | − | 共通コンポーネントを使用。本画面では釣果一覧（`tyokaList`）を選択状態にする。ナビ項目と釣果登録ボタンを含む |
| 2 | 画面タイトル | ラベル | ○ | 「釣果一覧」。魚種や釣り場の絞り込み条件をタイトルには含めない |
| 3 | 絞り込みチップ | 単一選択チップ | − | 「すべて」「魚種」「釣り場」「期間」「サイズ」。初期選択は「すべて」。選択肢は今回の設計案 |
| 4 | 釣果カード | リンク | − | カード全体が釣果詳細へのリンク。Figma上のサンプルは22件 |
| 5 | 釣果写真 | 画像 | − | カード上部に表示。現在のFigma画像はサンプル素材で、釣果ごとの写真は未設定 |
| 6 | 釣果カードタイトル | ラベル | ○ | 「月日＋（釣り場名）の釣果」の形式。例：「10月15日（宇野港）の釣果」。魚種名はタイトルに含めない。Figma上はサンプルデータ |
| 7 | 魚種・匹数 | ラベル | ○ | サブタイトルに魚種名と釣果数を表示。例：「アジ 3匹」。サイズ（cm等）は表示しない。Figma上はサンプルデータ |

## 5. アクション / イベント

| 操作（トリガー） | 挙動（処理内容） | 遷移先・結果 |

| サイドバーのナビ項目押下 | 共通ナビの定義に従って画面遷移 | 「map」→SCR-302、「釣果一覧」→SCR-101、「釣り場一覧」→SCR-301、「検索」→SCR-002、「お気に入り」→SCR-003（機能保留） |

| 一覧をスクロール | 続きの釣果カードを表示 | 同画面。追加読み込み・ページング方式は未定 |
