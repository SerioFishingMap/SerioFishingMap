## 2. 画面概要
釣り場をカードのグリッドで一覧表示する画面です。
サイドバーとメインコンテンツで構成します。画面上部に「釣り場一覧」と魚種「チヌ」での絞り込み状態を表示し、条件・件数・並べ替え操作の下に釣り場カードを並べます。

## 3. 画面レイアウト
**レイアウトの正典は Figma**。見た目の詳細は Figma を参照してください。

- **Figma フレーム URL**: https://www.figma.com/design/LX5UAOYXjKxQougVqVzViq?node-id=1159-2582

## 5. アクション / イベント

| 操作 | 挙動 | 遷移先・結果 |
| --- | --- | --- |
| 「地図で見る」押下 | 地図表示に切り替える | SCR-302 地図画面へ遷移。プロトタイプ設定済み |
| 釣り場カード押下 | 選択した釣り場の詳細を表示する | SCR-303 釣り場詳細画面へ遷移。15件すべて設定済み |
| 絞り込み条件押下 | 条件の選択・解除を切り替え、一覧を絞り込む | 動作プロトタイプ未設定 |
| 「条件をクリア」押下 | 絞り込みを解除する | 動作プロトタイプ未設定 |
| 並べ替え押下 | 並び順の選択・適用を行う | 条件・画面状態とも未確定のため未設定 |
| ページ送り押下 | 表示するカードのページを切り替える | ページ状態の画面が未作成のため未設定 |
| サイドバーのホームボタン押下 | ホーム画面を表示する | ホーム画面への既存プロトタイプ設定あり |
| サイドバー「＋」押下 | 釣果登録を開始する | SCR-103 を想定。プロトタイプ未設定 |

プロトタイプでは、遷移先が確認できる「地図で見る」と釣り場カードに遷移を設定しています。その他の操作は状態差分や遷移先の画面が未作成のため、未設定です。
