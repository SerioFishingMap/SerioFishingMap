# 釣り map 必要画面一覧

## 1. 本資料の目的

本資料では、釣り map に必要な画面を整理します。

API として管理される以下のデータを基準に、利用者が行う操作と必要画面を洗い出しています。

- 魚
- 釣果
- 釣行
- 釣行メンバー
- 釣り場

また、画面ごとに以下を記載します。

- 画面の役割
- 主な利用者
- 主な機能
- 主な遷移元
- 主な遷移先
- 開発優先度

---

## 2. 利用者の種類

### 2.1 一般利用者

釣果や釣行を登録し、過去の記録を閲覧する利用者です。

主な操作は以下です。

- 釣果の登録・閲覧・編集
- 釣行の登録・閲覧・編集
- 魚の検索・閲覧
- 釣り場の検索・閲覧
- 地図から釣り場を探す

### 2.2 管理者

システムで使用するマスタデータを管理する利用者です。

主な操作は以下です。

- 魚マスタの管理
- 釣り場マスタの管理
- 不正データや重複データの確認
