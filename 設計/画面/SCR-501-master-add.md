## 2. 画面概要
魚・釣り場などのマスタを追加する画面です。
Figma のキャンバスには「ユーザなどのマスタを追加していく画面 マスタに追加するのはユーザがマスタに未登録の魚などを自動的に追加していく。」という注釈が置かれています。
この注釈は**利用者の操作による追加ではなく、未登録データの自動追加**を主とすると読めるため、画面としての導線が必要かどうか自体が未確定です（課題2参照）。
[screen-list.md](./screen-list.md) では SCR-5xx（マスタ管理）の唯一の画面として採番しています。

## 8. 備考・課題
本設計書は 2026-08-31 に Figma フレーム（node-id=1158-2191）から新規に起こしたものです。**フレームがテンプレ既定の入力欄5つのみで、追加対象のマスタも入力項目も決まっていません。**画面として必要かどうかから確認が必要です。以下は仕様確定時に解消してください。

1. **入力項目・対象マスタが未確定（最重要）** — Figma には `Input Field` が5つ並んでいるだけで、ラベルは全て `Label`、値は全て `Value` です。**どのマスタ（魚／釣り場／道具／タックルなど）を追加するのか、1画面で複数種類のマスタを扱うのか、項目が何個必要なのかが一切読み取れません。**注釈は「ユーザなどのマスタ」と書いており、利用者マスタも対象に見えますが、**ログイン機能は [docs/tasks.md](../tasks.md) の D-06 で実装しない方針**のため利用者マスタは現時点で存在しません。
2. **画面としての導線が必要か自体が未確定** — Figma の注釈は「マスタに追加するのは**ユーザがマスタに未登録の魚などを自動的に追加していく**」です。自動追加が主なら、独立した追加画面ではなく [SCR-103 釣果登録画面](./SCR-103-catch-register.md) の入力時に裏で追加する仕組みで足ります。Figma のキャンバスにも**本フレームへ向かう矢印が1本もありません**（[screen-list.md](./screen-list.md) の SCR-501 の注記参照）。画面を残すか、SCR-103 の一機能に吸収するかを決める必要があります。
3. **マスタの編集・削除が無い** — 本画面は「追加」のみです。`version1.0` キャンバスには「自分が追加した魚情報は魚詳細から消せるようにしたい」という注釈があり、**削除の要求が存在します**。また [SCR-202 魚詳細画面](./SCR-202-fish-detail.md)・[SCR-303 釣り場詳細画面](./SCR-303-spot-detail.md) には `edit` という中身が空のフレームが置かれています。マスタの編集・削除をどこで行うか（詳細画面か、本画面の拡張か）を SCR-202 課題9・SCR-303 課題18 と一体で決める必要があります。
4. **URL が未定** — Figma のアドレスバーはテンプレ既定の `www.url.com` のままで、URL の手がかりがありません。[README.md](./README.md) の「ドメイン用語」にもマスタに対応する URL がないため、命名から決める必要があります。
5. **対象ユーザーの想定が未整理** — マスタの追加は本来は管理者の操作ですが、[docs/tasks.md](../tasks.md) の D-06 により**ログイン機能を実装せず権限による出し分けを行わない**方針です。誰でもマスタを追加できる状態で問題ないか（不正なマスタが増えないか）、確認が必要です。課題2 の自動追加方式なら権限の問題は生じません。
6. **古い Navigation Rail が Figma に残存** — 本フレームには Navigation Rail が2つ重なっており、片方は4項目目が `入力` で FAB が非表示（`version1.0` 相当の消し忘れ）です。**正は `map` / `一覧` / `検索` / `お気に入り` ＋ FAB** です（[SCR-001](./SCR-001-home.md) 課題11・[SCR-103](./SCR-103-catch-register.md) 課題12と同一）。あわせて、ナビの選択中表示（背景色付きの角丸）が `map` に付いたままである点も他画面と同様に未整理です。
7. **登録・キャンセルのボタンが無い** — Figma のフレームに送信ボタン・キャンセルボタンが存在しません。フォームの確定操作、確定後の遷移先、確認ダイアログの要否がすべて未確定です（[SCR-103](./SCR-103-catch-register.md) 課題4と同一）。
8. **[SCR-103 釣果登録画面](./SCR-103-catch-register.md) とレイアウトがほぼ同一** — 入力欄の個数（本画面5つ／SCR-103 は4つ）以外は Navigation Rail の二重配置を含めて同じ構成です。共通のフォームテンプレートとして定義するか要確認。
9. **バリデーションが未定** — 各 `Input Field` は `Error` 要素を持ちますが Figma 上は非表示です。必須チェック・形式チェックの内容、エラー文言、表示契機がすべて未確定です。マスタ特有の重複チェック（同名の魚・釣り場が既にある場合）も要確認。**Figma からは必須可否・桁数・形式が取れないため、ここは人が決める必要があります。**
10. **画面タイトルが無い** — フレーム名は「マスタ追加画面」ですが、フレーム内に見出しに相当するテキストがありません。[SCR-101](./SCR-101-catch-list.md)・[SCR-201](./SCR-201-fish-list.md) などが持つ Top app bar も配置されていません。
11. **アイコンがすべてプレースホルダ** — 各ナビ項目の最終アイコンが未定。
12. **SP レイアウトが未定** — 入力欄の幅・ラベルの配置（上／横）の切り替え基準が未確定です。
13. **Material テンプレの残骸** — `Input Field` の `Label` / `Value` / `Description`（非表示）/ `Error`（非表示）、Navigation Rail の `Nav item 5`〜`7`（非表示）が残っています。
