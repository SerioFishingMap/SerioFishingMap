## 2. 画面概要

魚種または釣り場の情報を追加するフォームです。魚種フォームと釣り場フォームを用意し、それぞれ5つの入力欄、追加、キャンセル操作を配置しています。入力欄は共通のInput Fieldコンポーネント、種別タブと追加・キャンセル操作は専用コンポーネントのインスタンスを組み合わせています。フォーム外に残っていたLabel画像レイヤーと旧注釈を削除し、入力欄の項目名は編集可能なテキストラベルとして表示します。サイドバーは画面フレーム内に収め、マスタ画面ではホームへのボタンを非表示にしています。

元のFigma注釈には、釣果登録で未登録の魚などを自動追加する案が記載されています。この画面から利用者が手動登録する案との役割分担は決まっていません。

画面に表示している入力項目・プレースホルダーはサンプルです。必須項目や保存後の挙動を確定した仕様として扱わないでください。

## 3. 画面レイアウト

画面構成とコンポーネントはFigmaを正典とします。魚種・釣り場フォームは別フレームで用意し、両フレームで共通のサイドバーとInput Fieldコンポーネントを使います。種別タブ、追加ボタン、キャンセルボタンは専用コンポーネントのインスタンスです。簡易ワイヤーは項目と操作の関係を示します。

- **釣り場フォーム案**: https://www.figma.com/design/LX5UAOYXjKxQougVqVzViq/%E3%82%BB%E3%83%AA%E3%82%AA%E9%87%A3%E3%82%8AMAP--Copy-?node-id=3738-2740
- **入力状態サンプル**: https://www.figma.com/design/LX5UAOYXjKxQougVqVzViq/%E3%82%BB%E3%83%AA%E3%82%AA%E9%87%A3%E3%82%8AMAP--Copy-?node-id=3738-2842

簡易ワイヤー（魚種フォーム）:

    ┌───────────────────────────────────────────────────────────┐
    │ 共通サイドバー │ マスタ追加                               │
    │                │ マスタに登録されていない情報を追加します │
    │                │ [魚種を追加] [釣り場を追加]              │
    │                │ ┌─────────────────────────────────────┐ │
    │                │ │ 魚種情報                            │ │
    │                │ │ 魚種名 *    [例：チヌ             ] │ │
    │                │ │ 説明        [魚の特徴や見分け方   ] │ │
    │                │ │ 分類        [例：スズキ目・タイ科 ] │ │
    │                │ │ 釣れる時期  [例：春〜秋           ] │ │
    │                │ │ 生息域      [例：沿岸・内湾       ] │ │
    │                │ │                  [キャンセル][追加] │ │
    │                │ └─────────────────────────────────────┘ │
    └───────────────────────────────────────────────────────────┘

釣り場フォームでは、入力欄を「釣り場名」「所在地」「説明」「釣れる魚種」「アクセス情報」に差し替えています。

## 5. アクション / イベント

| 操作 | 挙動 | 遷移先・結果 |

| キャンセルボタン | 入力を破棄する想定 | 戻り先は未確定 |
