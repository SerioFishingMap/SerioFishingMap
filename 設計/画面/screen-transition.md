# 画面遷移図（釣りマップ）

アプリ全体の画面遷移を Mermaid で表します。ノードは画面ID、矢印は遷移（親→子）です。
画面を追加したらノードと矢印を追記してください。画面IDは [screen-list.md](./screen-list.md) と一致させます。

> URL・トリガーは現時点の**仮案**です。仕様確定時に更新してください。
> **権限による分岐は当面ありません**（ログイン機能は保留 → [README.md](./README.md) の「権限の扱い」）。以下の条件表に残る権限の記述は再検討時の参照用です。
> **釣行（SCR-4xx）のノードはありません** — 釣行は画面を持たないドメイン概念です（[screen-list.md](./screen-list.md) の「釣行（SCR-4xx）— 欠番」参照）。

実線のうち以下は **Figma キャンバス上の矢印**を根拠としています（`version2.0` 領域）。それ以外はモックからの推測です。

```
ホーム画面 → 入力フォーム / 検索 / map / 釣り場一覧 / 魚一覧表示 / 釣果一覧
map → map詳細 ／ 魚一覧表示 → 魚詳細 ／ 釣り場一覧 → map詳細
検索 → 魚詳細 / map詳細 / 釣果詳細 ／ 釣果一覧 → 釣果詳細
```

> **マスタ追加画面（SCR-501）へ向かう矢印は Figma に1本もありません。**遷移元が不明のため、下図では孤立ノードとして点線で表記しています（[SCR-501](./SCR-501-master-add.md) の課題2）。

## 全体遷移図
```mermaid
flowchart TD
    Start((開始)) --> SCR_001["SCR-001 ホーム"]

    %% ホームからの導線（Figma の矢印を根拠とする）
    SCR_001 --> SCR_002["SCR-002 検索"]
    SCR_001 --> SCR_101["SCR-101 釣果一覧"]
    SCR_001 --> SCR_103["SCR-103 釣果登録"]
    SCR_001 --> SCR_201["SCR-201 魚一覧"]
    SCR_001 --> SCR_301["SCR-301 釣り場一覧"]
    SCR_001 --> SCR_302["SCR-302 地図"]

    %% 検索（Figma の矢印を根拠とする）
    SCR_002 --> SCR_102["SCR-102 釣果詳細"]
    SCR_002 --> SCR_202["SCR-202 魚詳細"]
    SCR_002 --> SCR_303["SCR-303 釣り場詳細"]

    %% 釣果
    SCR_101 --> SCR_102
    SCR_102 --> SCR_104["SCR-104 釣果編集"]
    SCR_102 --> SCR_202
    SCR_102 --> SCR_303
    SCR_103 --> SCR_102

    %% 魚図鑑
    SCR_201 --> SCR_202
    SCR_202 --> SCR_102
    SCR_202 --> SCR_303

    %% 釣り場
    SCR_301 --> SCR_303
    SCR_301 --> SCR_302
    SCR_302 --> SCR_303
    SCR_303 -->|"釣果登録"| SCR_103

    %% 共通サイドバーの FAB（設計書を起こした画面のみ記載。実際は全画面共通）
    SCR_302 --> SCR_103
    SCR_002 --> SCR_103
    SCR_301 --> SCR_103
    SCR_201 --> SCR_103

    %% マスタ管理（Figma に遷移の矢印が無い）
    UNKNOWN(["遷移元 不明"]) -.-> SCR_501["SCR-501 マスタ追加"]

    %% 仮説（モック・Figma から推測。未確定）
    SCR_202 -.->|"この魚が釣れる釣り場（仮）"| SCR_301
    SCR_303 -.->|"最近の釣果 横のアイコン（仮）"| SCR_101
    SCR_303 -.->|"釣果リスト項目押下（仮）"| SCR_102
    SCR_001 -.->|"ナビ「お気に入り」（仮）"| SCR_003["SCR-003 お気に入り"]
```

> ノードIDにはハイフンが使えないため `SCR_001` のようにアンダースコアを使い、表示名（ラベル）に `SCR-001` を書きます。

## 凡例
| 表記 | 意味 |
| --- | --- |
| `["SCR-XXX 画面名"]` | 通常画面 |
| `(["…不明"])` | 遷移元・遷移先が特定できていないことを表すプレースホルダ（画面ではない） |
| `((開始))` | 開始 / エントリーポイント |
| `-->` | 遷移（親→子） |
| `-->|ラベル|` | 遷移（ラベルはトリガー操作） |
| `-.->` | 遷移（**仮説**。モックからの推測で未確定のもの） |
| `%% コメント` | 図中コメント（描画されない） |
